Automated Inventory Database Server
A hands-on Linux and PostgreSQL project focused on database administration, backup automation, and system management.

Technologies

* Ubuntu Server
* PostgreSQL
* Bash
* Cron
* Git
* Project Status
* In progress.

Goals

* Design and manage an inventory database
* Automate PostgreSQL backups using Bash
* Schedule backup jobs with cron
* Maintain execution logs
* Practice Linux server administration
